# AsteriaLauncher 1.5 — как запустить

Лаунчер теперь простой: игра, версии, моды, бесплатные визуалы Asteria, скины, серверы, настройки и автообновление.
Подписок, кланов и статистики больше нет — **сервер Asteria (backend) не нужен**.

## Что сделать
1. Распакуйте архив поверх папки проекта.
2. Запустите `build-launcher.bat` (нужен Node.js LTS: https://nodejs.org) и установите то, что появится в папке `release`.
3. Чтобы игроки получали обновления сами — опубликуйте на GitHub (раздел ниже).

## Моды Asteria (бесплатно, ставятся сами)
* **Asteria** — звезда перед ником в табе и над головой, ваш скин и плащ, настройки из лаунчера применяются прямо в игре, фон главного меню.
* **Asteria Visuals** — HUD (стили «Кристалл» и «Линии»), шлейфы, круги прыжка, частицы вокруг, эффект убийства, частицы удара, метка цели, зум и др.
  Меню в игре — **Right Shift**. Работает на 1.16.5, 1.20.1 и 1.21.4. Только визуальные эффекты — без нечестных преимуществ.
* Если у версии выбран загрузчик **Vanilla** (страница «Версии»), моды не ставятся — выберите **Fabric**.

## Свои HD-картинки
Папка `src/assets/art` — положите туда картинки с именами из `README.txt` (hero.jpg, news-wipe.jpg, v-1.16.5.jpg …) и пересоберите лаунчер.
Готовые промпты для генератора картинок — `src/assets/art/PROMPTS_RU.md`. Без своих картинок показываются официальные HD-арты Minecraft.

## Discord
Статус «Играет на SafiMine · IP · версия» работает сразу (Application ID встроен). Чтобы вместо «?» была иконка:
discord.com/developers/applications → ваше приложение → **Rich Presence → Art Assets** → загрузите `build/icon.png` с именем **`logo`**, и в **General Information → App Icon** — тот же файл.

## Ивенты, новости, ссылки (необязательно)
Тексты лежат в `src/config.default.json`. Менять их без пересборки можно через админ-панель: запустите `start-backend.bat`, откройте http://127.0.0.1:8080/admin.

## GitHub — пошагово (если вы «овощ», это нормально 🙂)
GitHub нужен для **автообновления лаунчера у игроков** и как запасной адрес для скачивания мода Asteria.
Репозиторий: https://github.com/FilonisSF/AsteriaLauncher (если его ещё нет — создайте пустой с этим именем: New repository → `AsteriaLauncher` → Create, ничего не добавляя).

**Какие файлы закидывать:** всю папку проекта целиком. Вручную ничего выбирать не нужно — файл `.gitignore` сам не пустит лишнее и секретное:
* попадёт: `src`, `electron`, `backend` (без `data`), `mods` (исходники и `mods/dist/asteria-core-*.jar`), `server-plugin`, `tools`, `build` (иконка), `.github` (сборка на GitHub), `package.json`, `*.bat`, `README-SETUP.md` и т.д.;
* **не** попадёт: `node_modules`, `release`, `dist`, `backend/data` (ключи, подписки, токены), `*.pem`, `server-side` (исходник SafiClan).
Не загружайте файлы через кнопку «Upload files» на сайте — так `.gitignore` не работает и можно выложить ключи. Используйте способ А или Б.
Папка `server-side/SafiClan` (плагин кланов) на GitHub не уходит — лаунчеру она там не нужна. Если хотите хранить её на GitHub, сделайте для неё отдельный **приватный** репозиторий.

**Вариант А — одним файлом**
1. Установите Git: https://git-scm.com/download/win (все галочки по умолчанию).
2. Двойной клик `publish-to-github.bat`. В первый раз откроется окно входа в GitHub — войдите.
3. На вопрос «Выпустить обновление?» ответьте `y`. GitHub сам соберёт установщик (≈10 минут, вкладка Actions), и все установленные лаунчеры обновятся сами.
   Перед следующим выпуском увеличьте `"version"` в `package.json` (например 1.3.0 → 1.3.1).

**Вариант Б — мышкой (GitHub Desktop)**
1. https://desktop.github.com → установите, войдите в аккаунт.
2. File → Add local repository → выберите папку проекта → «create a repository» (если спросит).
3. Внизу слева напишите «Обновление 1.3.0» → **Commit to main** → **Publish repository** (имя `AsteriaLauncher`, галочку «Keep this code private» можно оставить).
4. Выпуск обновления: вкладка History → правый клик по последнему коммиту → **Create Tag** → `v1.3.0` → **Push origin**.

Важно: если репозиторий **приватный**, игроки не смогут скачивать обновления с GitHub. Для автообновления сделайте его публичным (Settings → Danger Zone → Change visibility) — секретов в нём нет благодаря `.gitignore`.

## Для разработчика: сборка модов
`mods/toolchain/build.sh <версия> <папка библиотек> <маппинги yarn>` — сборка без Gradle (javac + собственный ремаппер + проверка всех ссылок `Verify.java`). Подробности в начале `build.sh`.
