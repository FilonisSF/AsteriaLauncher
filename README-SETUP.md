# AsteriaLauncher 1.3 — что нового и как запустить

## Коротко: что сделать (10 минут)
1. Распакуйте архив **поверх** старой папки проекта (или в новую — тогда скопируйте туда `backend\data` из старой: там ключ подписи).
2. Запустите `start-backend.bat` — это сервер подписок/скинов. Лаунчер на этом ПК найдёт его **сам** (больше ничего вписывать не нужно).
3. Запустите `build-launcher.bat` — он соберёт установщик в папке `release`. Установите его поверх старого лаунчера.
   (Нужен Node.js LTS: https://nodejs.org — один раз.)
4. Выдайте себе PREMIUM: http://127.0.0.1:8080/admin → «Подписки». В лаунчере он появится в течение минуты (или кнопка «Обновить статус» в профиле).

## Почему раньше не было скина, плаща и звезды
Мод Asteria просто не попадал в игру. Теперь моды собраны и лежат в `mods/dist`, установщик кладёт их внутрь лаунчера, а при запуске игры лаунчер сам копирует их в сборку.
Проверено загрузкой в настоящем Fabric (все миксины применились) для версий:

| Версия | Звезда, скины, плащи, живые настройки | Визуалы PREMIUM |
|---|---|---|
| 1.16.5 | да | да |
| 1.20.1 | да | да |
| 1.21.4 | да | да |
| 1.21.11 | да | пока нет (в 1.21.6+ Mojang полностью переписал отрисовку интерфейса) |
| 1.8.9, 1.12.2 | пока нет — запускается чистая игра | нет |

**Значок как у Lunar.** Звезда перед ником в табе и над головой видна вам и всем игрокам AsteriaLauncher. Плагин на сервере больше не нужен.
Чтобы *другие* игроки видели ваш значок/скин/плащ, сервер Asteria должен быть доступен им из интернета (см. ниже). Пока он только на вашем ПК — это видите только вы.

## Визуалы
* Меню в игре — **Right Shift** (меняется в лаунчере: Визуалы → «Клавиши в игре», или в игре: Настройки → Управление → Asteria).
* Зум — **C**, колесо мыши — сила зума.
* У каждой функции можно назначить свою клавишу (кнопка с клавиатурой на карточке).
* Всё, что меняете в лаунчере, сразу применяется в запущенной игре, и наоборот — изменения из игрового меню возвращаются в лаунчер.
* Только визуальные эффекты: никаких ESP сквозь стены, x-ray и прочих нечестных функций (из присланных сборок взяты только идеи визуалов, код написан заново).

## Кланы и ивенты (новое в 1.3)
Во вкладке **«Кланы»** — топы (уровень, казна, сапфиры, убийства, честь, разбойники, участники), составы с ролями, войны и союзы. Названия раскрашены так же, как в игре (градиенты из `clan-gradients`). На главной — блок **«Ивенты сервера»** с живыми таймерами (без crash).
Данные шлёт сам сервер, нужно один раз:
1. **SafiClan** (исходник в `server-side/SafiClan`): соберите как обычно (`gradlew build` или в IDEA), положите jar на сервер.
   В `plugins/SafiClan/config.yml` **добавьте** блок (старый конфиг сам не обновится):
   ```yaml
   launcher-sync:
     enabled: true
     url: "https://api.safimine.ru/asteria"   # адрес бэкенда лаунчера
     secret: "Stats key из окна start-backend / админ-панели"
     interval-seconds: 30
   ```
   Затем `/clan admin reload`.
2. **AsteriaBridge** (`mods/dist/AsteriaBridge.jar`, уже собран) — положите в `plugins`. В его `config.yml` впишите тот же `url` и `secret`.
   Раздел `events:` уже заполнен вашими плейсхолдерами (`%safiblackauction_bairdropx_cargo%` и т.д.).
3. Тексты, цвета и головы ивентов меняются в админ-панели → «Содержимое лаунчера» → «Ивенты сервера». ID ивента должен совпадать с ID в `events:` у AsteriaBridge.

## Админ-панель (http://127.0.0.1:8080/admin)
* **Подписки** — выдать/снять PREMIUM, список игроков.
* **Содержимое лаунчера** — визуальный редактор: описание сервера, новости с картинками (загрузка прямо с ПК), ивенты, ссылки, команды, картинки версий, Discord. Справа — превью.
* **Серверы** — добавляйте свои серверы: они появятся во вкладке «Серверы» с онлайном, иконкой и кнопкой «Зайти», и в списке серверов игры.
* **Моды и ключи** — какие jar-файлы раздаёт сервер.

## Сервер Asteria для всех игроков
Чтобы подписки/скины/значки работали у всех, запустите `backend` на VPS (Node.js 18+): `node backend/server.cjs` за nginx с HTTPS, адрес вида `https://api.safimine.ru/asteria`. Скопируйте туда всю папку проекта вместе с `backend/data` и `mods/dist`.
Если адрес другой — впишите его в `electron/main.cjs` (`API_DEFAULT`) и пересоберите лаунчер, либо в «Содержимое лаунчера» → JSON → поле `"api"`.

## GitHub — пошагово (если вы «овощ», это нормально 🙂)
GitHub нужен для **автообновления лаунчера у игроков** и как запасной адрес для скачивания мода Asteria.
Репозиторий: https://github.com/FilonisSF/AsteriaLauncher (если его ещё нет — создайте пустой с этим именем: New repository → `AsteriaLauncher` → Create, ничего не добавляя).

**Какие файлы закидывать:** всю папку проекта целиком. Вручную ничего выбирать не нужно — файл `.gitignore` сам не пустит лишнее и секретное:
* попадёт: `src`, `electron`, `backend` (без `data`), `mods` (исходники и `mods/dist/asteria-core-*.jar`), `server-plugin`, `tools`, `build` (иконка), `.github` (сборка на GitHub), `package.json`, `*.bat`, `README-SETUP.md` и т.д.;
* **не** попадёт: `node_modules`, `release`, `dist`, `backend/data` (ключи, подписки, токены), `*.pem`, PREMIUM-визуалы `asteria-visuals-*.jar`, `server-side` (исходник SafiClan).
Не загружайте файлы через кнопку «Upload files» на сайте — так `.gitignore` не работает и можно выложить ключи. Используйте способ А или Б.
Папка `server-side/SafiClan` (плагин кланов) на GitHub не уходит — лаунчеру она там не нужна. Если хотите хранить её на GitHub, сделайте для неё отдельный **приватный** репозиторий.

**Вариант А — одним файлом**
1. Установите Git: https://git-scm.com/download/win (все галочки по умолчанию).
2. Двойной клик `publish-to-github.bat`. В первый раз откроется окно входа в GitHub — войдите.
3. На вопрос «Выпустить обновление?» ответьте `y`. GitHub сам соберёт установщик (≈10 минут, вкладка Actions), и все установленные лаунчеры обновятся сами.
   Перед следующим выпуском увеличьте `"version"` в `package.json` (например 1.3.0 → 1.3.1).

**Вариант Б — мышкой (GitHub Desktop)**
1. https://desktop.github.com → установите, войдите в аккаунт.
2. File → Add local repository → выберите папку проекта → «create a repository» (если спросит).
3. Внизу слева напишите «Обновление 1.3.0» → **Commit to main** → **Publish repository** (имя `AsteriaLauncher`, галочку «Keep this code private» можно оставить).
4. Выпуск обновления: вкладка History → правый клик по последнему коммиту → **Create Tag** → `v1.3.0` → **Push origin**.

Важно: если репозиторий **приватный**, игроки не смогут скачивать обновления с GitHub. Для автообновления сделайте его публичным (Settings → Danger Zone → Change visibility) — секретов в нём нет благодаря `.gitignore`.

## Для разработчика: сборка модов
`mods/toolchain/build.sh <версия> <папка библиотек> <маппинги yarn>` — сборка без Gradle (javac + собственный ремаппер + проверка всех ссылок `Verify.java`). Подробности в начале `build.sh`.
