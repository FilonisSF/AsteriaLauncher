Ивенты сервера

Карточки «Ивенты сервера» на главной. Таймер и название с цветами приходят с сервера (плагин AsteriaBridge, раздел events в его config.yml) — ID здесь и там должен совпадать. Голова — хэш текстуры из basehead (или оставьте пустым).

Как это увидят игроки

Изменения уходят в лаунчеры после «Сохранить для всех» — игроки увидят их при следующем запуске лаунчера.

Серверы во вкладке «Серверы»

Главный сервер (вкладка «Содержимое») показывается первым. Здесь — дополнительные: свои режимы, тестовый сервер, сервера партнёров. Лаунчер сам покажет онлайн и иконку, добавит их в список серверов игры, а кнопка «Зайти» подключит сразу.

PREMIUM-визуалы

Отдаются только игрокам с подпиской. Если лаунчер собран вместе с модами (папка mods/dist), загружать ничего не нужно — они уже здесь (build). Загруженный файл заменяет собранный.

Бесплатный мод Asteria

Нет ключа подписи. Выполните node tools/gen-keys.cjs и пересоберите моды, иначе визуалы будут заблокированы у всех.
